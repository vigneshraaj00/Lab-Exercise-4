## Aim:

To design a low-fidelity wireframe for a food delivery application using Balsamiq, covering the major screens involved in the food ordering process.

## Algorithm:

1. Design the **Welcome Screen** with the application name and a short introduction.

2. Design the **Login/Signup Screen** with fields for user credentials and authentication options.

3. Design the **Home Screen** with a search bar, food categories, offers, and recommended restaurants.

4. Design the **Restaurant/Menu Screen** displaying restaurant details, food items, prices, and Add to Cart options.

5. Design the **Cart/Checkout Screen** containing selected items, order summary, delivery details, payment option, and Place Order button.

6. Connect the screens in sequence to represent the complete food ordering flow.

7. Apply basic wireframing principles such as alignment, spacing, grouping, and clear navigation.

8. Review the wireframe and verify that the user can move from selecting a restaurant to placing an order.
